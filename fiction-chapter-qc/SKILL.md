# ✅ 小說章節／番外 QC 驗證（Fiction Chapter QC）

> 動筆前盤點 canon ＋ 寫完跑腳本，把重複句、簡體字殘留、口頭禪超標一次抓乾淨。
> 適用：任何長篇小說的章節或番外，交稿試讀前執行。

## 一、動筆前：盤點 canon（防重複）

- 列出既有章節＋番外，記下已用的**場景與意象**（例：已用過書桌／稿紙／化妝室／「溫豆漿結尾」）——新場景不得主題重複
- 記下既有**逐字名句**，寫完後對掃（核心金句不可跨章無意識複用）
- 新番外先確認定位：補完哪個留白？對應哪條敘事支線？

## 二、寫完後：跑 QC 腳本

```bash
python scripts/verify_chapter_qc.py \
  --file <新稿路徑> \
  --refs <正文/既有番外路徑,逗號分隔>
```

輸出與門檻：
- 風格詞計數（預設門檻範例：低聲說 ≤12、可是 ≤4；其餘只報數不設限）
- 簡體字候選（啟發式，命中需人工確認）
- 與 refs 的 8+ 字逐字重複（0 為過）
- 中文字數統計

有問題 → 改寫 → 重跑直到全過 → 再交由審稿者試讀。

## 三、踩坑

1. **簡體檢查會誤報**：台／上／你／到／前／加／口 等字繁簡同形——腳本用 curated simplified-only 字表，命中仍要人工看
2. **逐字重複要連既有番外一起掃**：不只對正文章節，若番外之間的特定比喻複用，只掃正文會抓不到
3. **結尾意象重複**：上一篇以特定意象收尾，下一篇就不能再用同一意象收尾——盤點時特別標記各篇結尾
4. **風格詞門檻可依作品調整**：不同文風作品可透過 `--tics` 參數傳入各自的易氾濫詞彙
