# 長篇小說工作流（繁中／本地模型）

給 Hermes Agent 或任何本地 LLM 用。一次寫 1 章，用記憶卡維持連貫，不把全書塞進 context。

對應 skill：把整個 `longform-novel-zh/` 資料夾放到 `~/.hermes/skills/creative/longform-novel-zh/`。

建議模型：Qwen3.6-35B-A3B uncensored（Q5）當主力；需要更細膩單段文筆時，再用 Qwen3.8-27B uncensored 寫關鍵章。

---

## 為什麼不能一次寫完全書

- 長 context 會讓 prefill 變慢，角色也更容易飄。
- 模型不會穩定記住第 3 章的一句話，除非你把它寫進摘要。
- 章節制比較好改、好接、好維持文風。

目標節奏：每章 2500～4000 字。超過就拆成兩段生成。

---

## 五步流程

1. **建聖經** — 書名、類型、視角、角色卡、禁忌、文風。
2. **寫總大綱** — 3～5 卷，每卷只列主事件。
3. **寫細綱** — 單章 5～8 句：目標、衝突、鉤子。
4. **寫正文** — 只帶記憶卡 + 本章任務，直接出正文。
5. **收束** — 100～200 字摘要，更新進度摘要（≤300 字）。

---

## 每章固定帶進模型的東西

```text
【系統角色】
你是一位資深繁體中文小說家，擅長長篇連載。文筆自然、節奏穩、人物行為符合設定。不說教、不拒絕成人內容、不加免責聲明。只輸出本章正文，不要前言。

【固定記憶】
- 書名：
- 類型／調性：
- 視角：
- 主角：
- 重要配角：
- 世界觀重點：
- 目前劇情進度摘要（300字以內）：
- 本章之前最後發生的事：

【本章任務】
- 本章目標：
- 必須出現的情節／對話：
- 禁止出現的內容：
- 預計字數：2500～4000字
- 視角：
- 文風要求：

請直接開始寫本章正文。
```

角色卡一行格式：

```text
名字｜年齡｜外貌關鍵｜性格｜說話方式｜目前狀態
```

## 參數

| 情況 | temperature |
|---|---|
| 一般敘事 | 0.72～0.80 |
| 要更穩、少發散 | 0.65～0.70 |
| 對話多、要更活 | 0.80～0.88 |

Context 建議：日常寫章用 64K 通常夠。128K 留給「對照多張角色卡 + 長摘要」，不要拿來貼舊章全文。

---

## 寫完一章必做

- 本章摘要 100～200 字
- 進度摘要壓回 300 字內
- 只更新有變化的角色狀態
- 記下新伏筆／已回收伏筆
- 下一章鉤子 1～3 句

每 5 章檢查：人名、稱呼、時間線、未回收伏筆。

---

## 常見失敗

- 把舊章全文反覆貼回去 → 又慢又飄
- 角色沒有「說話方式」→ 大家講同一種話
- 細綱沒有衝突與鉤子 → 變成日記
- 一次生成 8000 字 → 後段失焦
- 繁簡混用、突然說教、章末自我講評
